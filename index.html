일반 모드에서 휠로 확대·축소합니다. 설치물 배치·편집 중에는 휠이 방향 회전에 사용됩니다.

📍 설치물 배치하는 법

  1. 오른쪽 템플릿에서 원하는 설치물 선택
  2. 커서를 움직여 배치 위치 지정
  3. 좌클릭으로 설치 완료
  4. ESC로 배치 종료 및 템플릿 창 복귀

같은 설치물을 연속으로 여러 번 배치할 수 있습니다. 벽은 바닥 타일의 경계선에 자동 정렬됩니다.

🧱 바닥 타일·벽면 묶음 설치

  1. 템플릿 하단에서 바닥 붓 크기 또는 벽 길이 설정 (최대 4)
  2. 배치할 바닥 또는 벽 템플릿 선택
  3. 원하는 위치를 좌클릭하여 일괄 설치

바닥: 1×1 / 2×2 / 3×3 / 4×4 (각 1·4·9·16칸)
벽: 모서리를 따라 1~4칸 연속 설치

🛠️ 배치물 편집 모드

설치물 좌클릭　현재 위치에서 반투명 선택
휠 위로　왼쪽으로 90° 회전
휠 아래로　오른쪽으로 90° 회전
SPACE　이동 편집 시작 · 커서를 따라 이동
좌클릭　방향·위치 변경 확정
DELETE / BACKSPACE　설치물 삭제
ESC　편집 취소 · 원래 상태 복원

편집 모드에서는 휠로 화면을 확대·축소할 수 없습니다.

💾 프로젝트 저장 및 불러오기

  • 저장 : 현재 공장 구조도 프로젝트 저장
  • 내 프로젝트 : 이전에 저장한 구조도를 선택하여 이어서 편집
  • PNG 출력 : 사업계획서에 넣을 구조도 이미지를 저장

프로젝트 보관함은 현재 PC의 브라우저에 저장됩니다. 사이트 데이터 삭제·다른 PC 사용에 대비하여 중요한 프로젝트는 ‘내 프로젝트 → 전체 백업’으로 따로 보관하세요.

모델링 작업을 계속하려면 닫기를 누르세요.

📁 내 공장 프로젝트 보관함

현재 회사 PC의 이 브라우저에 저장됩니다. 저장된 구조도는 목록에서 선택해 다시 수정할 수 있어요.

저장한 프로젝트가 아직 없어요.

주의: 브라우저의 사이트 데이터 삭제, 다른 PC·다른 브라우저에서는 목록이 유지되지 않을 수 있어요. 중요한 구조도는 전체 백업을 권장해요.
